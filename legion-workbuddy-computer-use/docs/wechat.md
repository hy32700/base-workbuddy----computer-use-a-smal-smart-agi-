# 微信下达任务与推送

本项目使用 WorkBuddy 自身的微信入口。可以通过已经绑定的微信助理和电脑上的 WorkBuddy 聊天，在同一对话里接收任务结果。需要手机系统收到任务完成或待确认通知时，可使用 WorkBuddy 微信小程序的订阅通知。

## 设置并验收微信小程序通知

1. 在拯救者上登录 WorkBuddy 桌面版，打开侧栏的「连接移动端」，允许手机连接这台电脑。
2. 在微信打开 WorkBuddy 小程序，登录同一账号并选择本机。桌面操作测试期间保持电脑在线，Windows 已登录，内屏上打开可测试的窗口。
3. 从小程序发起一个本机任务。首次测试可以发送 `请通过 desktop-coordinator.get_status 读取运行状态，只回复是否监控及是否有活动任务。`
4. 在这个任务的订阅提示中选择通知并完成微信授权，然后离开会话页面，等待手机上出现实际通知。完成通知通常针对由小程序发起的任务，单次授权有对应的发送次数限制。 [WorkBuddy 多端协同和通知说明](https://www.codebuddy.cn/docs/workbuddymini/features/Multidevice#任务通知)
5. 确认只读流程后，再从手机发起[三聊天工作流](workflow.md)的验收。核对调度报告、手机实际结果和会话是否正常结束。

如果你已经使用 **微信助理 / ClawBot**，可以继续使用自己的绑定，在手机发一条只读测试指令并核对该会话返回的消息。微信聊天中的结果回复和小程序的订阅通知是两个入口，分别以手机收到的内容验收。 [WorkBuddy 移动端集成入口](https://www.codebuddy.cn/docs/workbuddy/FirstTask)

只有启用了对应绑定与权限的环境才能接收通知。用户使用的 WorkBuddy 版本、登录账号、订阅状态和当前网络都会影响实际通知。项目配置只需要本地 Python 路径和 MCP 服务路径，微信授权在自己的 WorkBuddy 里完成。
